# librebot-rs

Bot Minecraft Java Edition en **Rust pur** — client protocole natif, sans Node, sans mineflayer, zéro token.

→ Voir [`librebot-rs/`](librebot-rs/) pour le code source, la documentation et les instructions de démarrage.

```bash
cd librebot-rs
cargo build --release
cp config.example.json config.json
cargo run --release
```
